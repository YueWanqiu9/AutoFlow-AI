## Features

- **AI需求解析**：提取服务类型、预约时间、地址、客户姓名、电话和紧急程度；真实模式支持结构化输出，失败保留原文并转人工审核。
- **多轮信息补全**：识别缺失字段，通过补问更新原工单，保护已有信息和人工明确清空的字段。
- **AI优先级辅助**：规则生成等级建议，AI 可辅助解释，运营确认最终等级和理由；不宣称预测模型。
- **AI处理建议**：整理待补信息、处理步骤和注意事项，支持采纳、修改和拒绝，AI 不可用时使用规则模板。
- **服务人员管理**：维护技能、服务区域与登记状态，保留人员操作记录。
- **人员匹配推荐**：规则评分与排序，展示匹配理由和风险；AI 不参与评分，也不改变候选结果。
- **智能派单（人员推荐＋运营确认派单）**：运营核对候选、填写确认人与原因后创建派单，更新人员占用并写入事件；不包含自动派单、排班算法或 GPS 调度。
- **完整Demo业务闭环**：一键演示解析、工单创建、两轮补全、人工审核、优先级确认、建议采纳、人员推荐、派单、接单与开始、服务完成，支持十步回看。

同时提供操作事件追踪、服务状态流转与异常登记、运营 Dashboard 和日报。关键业务变化与对应事件同事务保存，工单人工状态与派单服务进度独立管理。

## Technical Stack

- **Python**：业务模块、规则计算与测试，已验证环境为 Python 3.12.14。
- **Streamlit**：演示首页、运营工作台、项目介绍和数据看板。
- **SQLite**：工单、对话、人员、派单及事件持久化，支持增量迁移和事务。
- **OpenAI Structured Outputs**：真实模式下约束结构化响应，并进行本地校验和异常降级。

## Project Scope

- 本版本用于个人作品和面试展示，使用明确标记的模拟业务数据，非生产环境。
- AI 辅助整理信息、解释判断和提供建议，运营人员保留最终确认、异常处理和业务决策职责。
- 完整 Demo 使用预置解析及规则路径，客户回复、运营确认和服务执行均为模拟；不调用付费 AI，不宣称真实准确率或效率提升。
- 完整 Demo 记录统一标记 `is_demo=1`，使用独立 SQLite 库，不写入工作台业务库或 AI 调用日志；重复运行复用案例。
- 当前无登录和多租户权限，工作台数据由访问者共享；公开演示不得放入真实客户信息或付费密钥。
- SQLite 用于单实例演示；实际部署仍需核对目录权限、子进程能力和持久化策略，正式业务另需访问控制与备份规划。
